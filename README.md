# EIC-413: Mecánica de Suelos I (2026-S02)

¡Bienvenido al repositorio oficial del curso **EIC-413 Mecánica de Suelos I** para el segundo semestre de 2026! Aquí encontrarás todo el material complementario, presentaciones y herramientas interactivas de la asignatura.

## 👨‍🏫 Profesor
* **Prof. Jorge Arriagada**  
* Escuela de Ingeniería Civil, Universidad de Valparaíso (UV), Chile.

---

## 📁 Estructura del Repositorio

El material está organizado de la siguiente manera:
* 📁 `Slides/` - Presentaciones de clases en formato PDF.
* 📁 `Notebooks/` - Cuadernos interactivos de Jupyter (`.ipynb`) con ejercicios, simulaciones y análisis de datos en Python.
* 📁 `Applets/` - Aplicaciones interactivas en HTML para visualizar conceptos clave del suelo (relaciones de fase, granulometría, etc.).

---

## 🚀 Cómo usar este material

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com
   ```
2. **Ejecutar los Notebooks:** Recomiendo instalar [Anaconda](https://anaconda.com) o usar [Google Colab](https://google.com) para abrir los archivos `.ipynb`.
3. **Applets HTML:** Solo descarga los archivos de la carpeta `Applets/` y ábrelos con cualquier navegador web (Chrome, Edge, Firefox).
